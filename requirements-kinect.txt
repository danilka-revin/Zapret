# Опциональный драйвер Kinect 360 для scripts/kinect_depth_publisher.py.
#
# Для привязки выбранного RC_KINECT_PORT к физическому NUI Camera сейчас
# поддержан только libfreenect + PyUSB. OpenNI2 и ROS 2 могут импортировать
# кадры, но не сопоставляют этот USB-порт с выбранным источником; publisher
# откажется запускать их вместо явно выбранного Kinect.
# Этот файл НЕ подключён к requirements.txt: нужны системный libusb и драйвер.
#
# Проверить, что видит скрипт:
#   ./scripts/kinect_depth_publisher.py --list-backends
#
# ---------------------------------------------------------------------------
# 1) libfreenect (Kinect 360 по USB, выбранная USB-топология привязывается точно)
#    Debian/Ubuntu:  sudo apt install libfreenect-dev libusb-1.0-0 python3-dev
#    Затем в .venv:  .venv/bin/pip install freenect pyusb
#    Запуск:         ./scripts/kinect_depth.sh --foreground
#    pyusb перечисляет USB-устройства в порядке libusb, затем выбранная
#    RC_KINECT_PORT сопоставляется с индексом NUI Camera в libfreenect.
#
# 2) OpenNI2 / ROS 2 — альтернативные захватчики остаются заготовками,
#    но сейчас НЕ запускаются с RC_KINECT_PORT: общий URI/topic не позволяет
#    гарантировать, что кадр идёт именно с выбранной USB-топологии. Не
#    отключайте проверку и не считайте их работающей привязкой.
#
# Устанавливать в .venv после системных библиотек:
# freenect
# pyusb
