# Отброшенный пяти-классовый прототип

Это отдельный ранний эксперимент, **не итоговый обучающий набор**. Его
запуск прерван после 9 эпох и не опубликован. Аудит выявил дополнительные
смещённые рамки и настоящие столбики, которые цветовой фильтр предлагал
удалить. Кроме того, объединённый класс светофора не даёт обученного
подтверждения green, необходимого итоговому цветному кандидату.

Для воспроизведения итогового эксперимента используйте **соседний
`yolo-stop-refined-color/`** и `docs/VISION_IMPROVEMENT.md`. В нём сохранены
восемь классов, расширен аудит, а 13 настоящих/частичных cone-рамок возвращены
по явному списку `keepTrainConeLabels`. Никакой из этих наборов не является
независимо размеченной человеком ground truth. Канонический `yolo-stop/`
и его test не заменяются.
