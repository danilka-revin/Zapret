# Обновление программы BULKA с флешки

На компьютере с интернетом скачивается нужная ветка `danilka-revin/Zapret` и
готовится **один файл `robot-update.bulka`**. Робот принимает его с USB без
интернета. Это обновление веб-пульта и бортового экрана, **не прошивка Arduino**.

## Один раз: подготовить компьютер и робота

1. На роботе должна быть запущена версия программы с поддержкой USB-обновлений.
   Если она ещё не установлена, обновите робота обычным способом один раз.
   Рабочая копия должна быть Git-клоном проекта. Ветка на роботе и в пакете
   должна совпадать (обычно `main`).
2. На компьютере понадобятся Git, Python 3.9+ и OpenSSH с `ssh-keygen -Y sign`.
   На роботе нужны `git`, `findmnt` (из `util-linux`) и `ssh-keygen -Y verify`
   (из `openssh-client`). На компьютере с интернетом создайте ключ для подписи:

   ```bash
   mkdir -p ~/.ssh
   ssh-keygen -t ed25519 -f ~/.ssh/bulka-usb-update -C bulka-usb-update
   ```

3. Доверенным способом перенесите **только** публичный `bulka-usb-update.pub`
   на робота. В каталоге проекта на роботе:

   ```bash
   mkdir -p data
   printf 'bulka-update %s\n' "$(cat /путь/к/bulka-usb-update.pub)" > data/usb-update-signers
   ```

   Файл должен читаться пользователем, от которого работает веб-пульт, и не
   быть доступным посторонним на запись. Закрытый ключ `~/.ssh/bulka-usb-update`
   оставьте на компьютере; не кладите его на флешку и не добавляйте в Git.

## Каждый раз: записать файл и вставить флешку

На компьютере с интернетом в обычном Git-клоне проекта (не `--depth 1`):

```bash
python3 scripts/make_usb_update.py "/путь/к/флешке" --key ~/.ssh/bulka-usb-update
```

Скрипт берёт `main` **с GitHub**, не локальные изменения, и записывает файл
в указанную папку. Вместо флешки можно указать папку на компьютере, а потом
скопировать `robot-update.bulka` в корень флешки. Дождитесь окончания записи
и безопасно извлеките накопитель. Для другой ветки укажите `--branch имя-ветки`.
Чтобы получить меньший пакет, добавьте `--base` и полный хеш версии с команды
`git rev-parse HEAD` **на роботе**. Если не хватает базовых коммитов,
подготовьте полный пакет без `--base`.

**Остановите робота, включите E-STOP и оставьте его включённым до конца
обновления.** Подключите флешку к компьютеру робота. В веб-пульте оператора
откройте **«Обновить с GitHub» → «С флешки (без интернета)»**. Проверьте версию
и нажмите **«Установить обновление»**. Не извлекайте флешку до окончания.

### Чтобы робот обновлялся при подключении сам

Добавьте на роботе в `.env` строку `RC_USB_UPDATE_AUTO=1` и один раз
перезапустите веб-пульт штатным способом. Дальше достаточно остановить робота,
включить E-STOP и вставить флешку с подписанным пакетом. Пульт должен работать.
По умолчанию автоустановка выключена (`RC_USB_UPDATE_AUTO=0`), но установка
через пульт доступна.

Робот видит флешку **после монтирования Ubuntu**: обычно это происходит само
в сеансе рабочего стола (`/media/...` или `/run/media/...`). Без рабочего стола
настройте монтирование отдельно, например под `/mnt/bulka-update` с опциями
`ro,nosuid,nodev,noexec`, и задайте `RC_USB_UPDATE_MOUNT=/mnt/bulka-update`
в `.env`. У пользователя, от которого работает веб-пульт, должен быть доступ
на чтение флешки. Сам пульт не монтирует устройства и не требует для обновления
`sudo`.

## Проверки и журнал

- Пульт проверяет подпись установленным ключом, копирует пакет на диск и
  сверяет контрольную сумму. Скрипты с USB не запускаются. Более старая версия,
  разошедшаяся ветка и локальные правки блокируют обновление.
- `.env`, настройки и карты в `data/` сохраняются. Зависимости берутся только
  из `vendor/`. При ошибке проверки кода или установки базовых зависимостей
  исходники откатываются. OpenCV для камер необязателен: без подходящих колёс
  сохраняется предупреждение, не откат. Драйверы ROS 2 с флешки автоматически
  не пересобираются.
- Ход установки виден в окне обновления, результат — в `var/update-state.json`.
  Если автоустановка была пропущена до запуска, причина попадёт в журнал
  веб-пульта. После исправления проверьте пакет в пульте или подключите
  флешку заново.
