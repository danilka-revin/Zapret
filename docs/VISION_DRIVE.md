# YOLO для полигона: фото и видео из `yolo` на Google Диске

`models/vision/yolo-drive.pt` — отдельный детектор Ultralytics YOLOv8n. На входе обычное цветное фото или видео, на выходе рамки, классы и уверенность. Для распознавания не нужны репозиторий с данными, Kinect или повторное обучение.

| Выход модели | Что обведено рамкой |
|---|---|
| `traffic_light_red`, `traffic_light_yellow`, `traffic_light_green` | Корпус светофора с предполагаемым активным сигналом |
| `traffic_light` | Корпус с выключенным или неразличимым сигналом; **не** зелёный по умолчанию |
| `stop_sign` | Сам знак STOP, без стойки |
| `ground_bump` | Физическая кочка: деревянная накладка поперёк пола на этой трассе |
| `speed_bump` | Синий **знак** искусственной неровности, не препятствие на полу |
| `cone` | Оранжевый дорожный ограничитель; в этих съёмках в основном полосатые столбики с основанием |
| `pedestrian_crossing` | Знак пешеходного перехода, сохранён из исходной модели |

## Как посмотреть результат

Откройте [ноутбук](vision-drive/predict.ipynb) в Google Colab: он подключает ваш Диск, читает модель из `yolo/Результат YOLO 2026-11-18`, обрабатывает выбранный файл и сохраняет **новую копию** с рамками. Достаточно заменить имя в `source` и выполнить ячейки. Большое видео тоже можно прогнать непосредственно в Colab, без передачи через коннектор.

Или скачайте `yolo-drive.pt` и запустите рядом с ним на компьютере:

```bash
python -m pip install 'ultralytics==8.4.215'
yolo predict model=yolo-drive.pt source="video.mp4" imgsz=416 conf=0.25 iou=0.7 project=predictions
```

Вместо `video.mp4` можно указать JPG. Если запускаете из этого репозитория, укажите `model=models/vision/yolo-drive.pt`.

## Откуда взяты кадры

- В папке Диска на 18 ноября 2026 г. было **416 JPEG и 12 MP4**. У 415 JPEG проверены полные MD5 из Drive против байтов закреплённого архива проекта. Ещё один файл, `1794940326751.jpg`, совпадает по содержимому с `1794903271610.jpg`. Всего **308 уникальных фото**. [Список для `md5sum -c`](../datasets/yolo-drive/photos.md5). У восьми старых MP4 совпадают SHA-256. Для этой части использованы сохранённые группы, исходные кадры и разметка [родительского набора](VISION_ROBOT_TRAINING.md), а не повторная авторазметка. Шесть фото считаны непосредственно с Диска при сборке и проверены также по SHA-256.
- Три дополнительных MP4 скачаны непосредственно с Диска. SHA-256, назначение целых роликов и групп — в [source.json](../datasets/yolo-drive/source.json). Из `115744_254` взято 24 кадра в TRAIN; по 12 кадров двух проездов `124149_011` и `124149_236` оставлены в TEST. Номера кадров и рамки записаны в [video_boxes.csv](../datasets/yolo-drive/video_boxes.csv). В соседних кадрах цвет не переносился автоматически.
- `VID_20261118_120325.mp4` (774 772 865 байт) превышает лимит коннектора 100 МиБ. **Не использован** ни в обучении, ни в оценке.
- К исходной разметке добавлены [рамки самой кочки](../datasets/yolo-drive/ground_bumps.csv), в том числе на бывших «фоновых» кропах. Только в TRAIN добавлены 35 увеличенных фрагментов с контекстом. При обрезке переносятся **все** пересекающиеся рамки. Жёлтая тактильная плитка, штатив и рисунок на знаке не размечались как кочка.

Итого **356 TRAIN / 61 VAL / 24 TEST**. В TRAIN есть 87 рамок физической кочки, в VAL — 12, в TEST — 11. Часть изображений — производные одного кадра, а оба тестовых проезда сняты в том же помещении. Это **не** 441 независимая сцена. Новая разметка выполнена агентом визуально; унаследованная разметка частично эвристическая. Первые восемь ID сохранены, ID 8 добавлен только для офлайн-детектора. Исходные метки не менялись.

## Обучение и проверка

Начальные веса — `yolo-stop-robot.pt`. Восемь выходов перенесены по имени, девятый обучался для накладки на полу. AdamW, `lr0=0.001`, CPU, 416 px, batch 8, freeze 10, seed 17, лимит 24 эпохи, patience 10; без сдвига оттенка и отражения знаков. Checkpoint выбирается по **VAL mAP50–95**; TEST не участвует в выборе. Во время обучения на VAL также сравнили [416/640/832 px](../models/vision/training/drive/val-input-size.json) при conf=0.25: для просмотра выбран размер **416**, до проверки TEST.

**Обучение заняло 24 эпохи. Сохранены [веса 19-й эпохи](../models/vision/yolo-drive.pt) — лучшей по VAL.** На VAL mAP50 = 0.654, mAP50–95 = 0.504; на TEST mAP50 = 0.410, mAP50–95 = 0.293. Это метрики обнаружения объектов, а не процент правильно обработанных кадров. В среднем по TEST участвуют только классы с разметкой: жёлтого там нет.

SHA-256 `yolo-drive.pt`: `a536d49668d09848edef6e4aef82374736ac1b26b18f333f4cc3d23d198fb69f`.

Ниже — **непосредственный вывод PT**, без HSV, сглаживания или ансамбля. Сопоставление по IoU > 0.5, по одной рамке на объект, `imgsz=416`, `conf=0.25`, NMS IoU=0.7. На этих двух проездах лучше всего видны результаты для STOP и деревянной накладки. Основная ошибка со светофором — пропуск всего корпуса (13 из 16), а не только путаница между цветами. Есть кадры, где модель отдельно обводит накладку и знак, но пропускает видимый красный сигнал и дальние столбики.

Это модель для просмотра записей, не для автономной езды. Другие типы лежачих полицейских, улица, ночь и камера с другой экспозицией не проверены. Физическая высота неровности по рамке не измеряется. Рабочие веса `yolo-stop.pt`, пятиклассовый бортовой API, управление тягой и E-STOP оставлены без изменений.

## Воспроизвести обучение

Из корня проекта, в окружении [`requirements-vision-training.txt`](../requirements-vision-training.txt) (Python 3.11; для headless OpenCV см. комментарий в файле):

```bash
# Восстановить старую часть, не меняя разбиение.
python scripts/restore_vision_source.py --restore-missing --report .cache/vision/drive-source.json
python scripts/refine_vision_dataset.py --keep-color-classes \
  --output datasets/yolo-stop-refined-color --review datasets/yolo-stop-refined-color/review.json
python scripts/prepare_robot_vision_dataset.py

# Укажите свою локальную папку Drive. Обязательны три MP4 из source.json.
# Для старых фото допустима проверенная копия из snapshot. Собирается в новую папку.
python scripts/prepare_drive_vision_dataset.py --media '/путь/к/yolo'

OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 python scripts/train_vision.py \
  --data .cache/vision/yolo-drive/data.yaml --weights models/vision/yolo-stop-robot.pt \
  --output models/vision/yolo-drive-retrained.pt --device cpu --workers 0 --imgsz 416 \
  --batch 8 --epochs 24 --patience 10 --lr0 0.001 --freeze 10 --seed 17 --no-download

# Независимо проверить именно поставленный PT, а не обучать его снова:
python scripts/report_drive_vision.py --weights models/vision/yolo-drive.pt
```

Сборщик проверяет хэши, отклоняет точные дубли между выборками и перенос группы между ними; при добавлении новых видеокадров проверяет также pHash относительно других частей. Повторная сборка без необязательных прямых копий фото дала тот же fingerprint изображений, меток и разбиения: `27c5d2fa565fa1f7480cfa38660fbaa13de861659eecf23fe94ee54a2eadeb55`. Полные видео и каталоги изображений не входят в Git.

## Зеркальный вариант ×2

Это отдельный цикл дообучения, не замена исходному `yolo-drive.pt`. Для альбома создано по одной горизонтальной копии **к каждому из 416 имён** (в том числе к дублям); вместе с оригиналами это 832 файла, а не 832 независимые сцены. Фото для альбома сверены с `photos.md5`. Оригиналы не переписаны. Архив `416 зеркальных фото.zip` — для просмотра, **не** для добавления целиком в TRAIN.

В отдельном архиве `yolo-drive-x2.zip` лежит готовый YOLO-датасет. После исходного разбиения каждому из 356 учебных изображений (фото, вырезки, кадры) добавлено его горизонтальное отражение. **TRAIN 712, VAL 61, TEST 24**. Отражены все рамки: `cx → 1 − cx`; класс, `cy`, ширина и высота не меняются. Копия наследует группу исходника. Все исходные кадры и метки, включая VAL/TEST, сохранены побайтно. Дополнительных случайных горизонтальных или вертикальных отражений при обучении нет. Буквы STOP на зеркальных кадрах читаются наоборот; качество оценивается только на обычных кадрах.

```bash
python scripts/prepare_drive_vision_dataset.py --media '/путь/к/yolo' --mirror-train
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 python scripts/train_vision.py \
  --data .cache/vision/yolo-drive-x2/data.yaml --weights models/vision/yolo-drive.pt \
  --output models/vision/yolo-drive-x2-retrained.pt --epochs 8 --patience 5 --lr0 0.0005 \
  --freeze 10 --imgsz 416 --batch 8 --seed 17 --device cpu --workers 0 --no-download
# Отдельно, если нужны отражения всего исходного фотоальбома:
python scripts/mirror_drive_photos.py --media '/путь/к/yolo' --output album-mirrors.zip
```

Для большого ролика есть [ноутбук подготовки полной копии для разметки](vision-drive/prepare-long-video.ipynb). Он проверяет SHA-256 оригинала, сохраняет в ту же папку отдельный `VID_20261118_120325_review.mp4` без наложений, затем можно размечать кадры. **Ни в исходный набор, ни в этот вариант только с отражениями кадры пятиминутного ролика не включены.** Обозначение «×2» не означает, что его разметили.

### Результат дообучения ×2

Из 8 эпох по валидации выбрана 4-я. mAP50 на VAL: 0.654 → 0.667; на TEST: 0.410 → 0.419. mAP50–95 на TEST: 0.293 → 0.302. Доли — верно найденные / размеченные объекты. Порог уверенности 0,25, размер входа 416, совпадение рамок IoU > 0,5. Жёлтого на TEST нет; ×2 на VAL: 2/3. Проверка на тех же 24 незеркальных кадрах двух прежних проездов, не на новом ролике. Это сравнение двух версий, а не оценка независимого эффекта отражения: у модели ×2 были также дополнительные шаги обучения.
