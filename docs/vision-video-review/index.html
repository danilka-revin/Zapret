«Нет детекции» не всегда означает пропуск: объект мог выйти из кадра. Цвета шкалы — ответы модели, а не реальный сигнал светофора. Без ручной покадровой разметки это нельзя переводить в precision/recall.

YOLO + HSV fusion, тот же кандидат, что на фотографиях. Нет трекера, дополнительного эвристического детектора или сглаживания. Видео уменьшено только для показа после инференса. Воспроизведение без звука, с исходной средней частотой кадров; оригинальные временные метки сохранены в JSONL. Число у рамки — score, не измеренная точность. Рабочая модель робота не заменялась.
