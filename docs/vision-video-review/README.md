# Проверка кандидата на полных видео

**Выполнен новый инференс всех 8 исходных роликов: 2 283 кадра, 62.22 с.**
Пропуска кадров нет. Все 2 283 кадра полученных MP4 затем повторно
декодированы и сверены по количеству с исходниками и JSONL.

Интерактивный просмотр — `index.html` через HTTP / Live Preview
**«Видео распознавания»**. В плеере доступны 0.25× / 0.5× / 1×,
переключение роликов, переход к отмеченным ошибкам и скачивание MP4.
Обычная ссылка на путь файла в сообщении чата может дать 404: используйте
Live Preview или файловый просмотрщик Arena.

## Что именно проверялось

- Модель обработала **каждый декодированный кадр** каждого ролика.
- Визуально просмотрены **96 равномерно выбранных кадров** — по 12 от начала
  до конца каждого ролика — и дополнительно конкретные спорные соседние
  кадры по временным трассам. Это не утверждение о ручной разметке всех
  объектов на всех 2 283 кадрах и не имитация человеческого просмотра видео.
- Рамки не дорисовывались и не сглаживались. Нет трекера или добавочного
  эвристического ансамбля. Использован тот же `YoloDetector`: YOLO + HSV fusion,
  confidence=0.25, imgsz=512, prefer_red=False, CPU.
- Инференс — на исходном изображении 1280×720. Только затем для просмотра
  изображение уменьшено до 960×540 и добавлены подписи (итог 960×624).
- MP4: H.264 / yuv420p / faststart, без аудио, каждый исходный кадр сохранён,
  постоянная выходная частота равна средней частоте исходника. Поэтому темп
  приблизительно исходный; оригинальные PTS и время выходного видео есть в JSONL.

**Это не новый независимый тест:** отдельные кадры пяти этих роликов были
в train, двух — в val, одного — в test. Порог и веса в этой проверке не менялись.
Полной независимой ручной покадровой разметки нет: счётчики ответов
не являются precision, recall или измеренной долей ошибок.

В ролике **865** green выдан на **7 кадрах из 263**. Это число выходов модели,
а **не recall зелёного**: светофор виден не весь ролик. Прежняя оценка
`green=0/3` относилась к другому, разреженному test-набору фотографий/кадров;
этот прогон её не заменяет. Никакого вывода о нулевом риске ложного green
без полной независимой разметки делать нельзя.

Столбики заметно устойчивее светофора, но ложные боксы и потеря объектов
остаются. Знак неровности — отдельный класс, не детектор физической кочки
на полу. `pedestrian_crossing` — знак перехода, не класс людей.

**Вывод: кандидат по-прежнему не готов к автономной езде. Рабочие веса и
профиль робота не заменялись. Нового обучения в этом прогоне не было.**

## Артефакты и воспроизведение

- `summary.json` — профиль, версии, хэши, счётчики, интервалы ответов для всех роликов.
- `source.json` — закреплённый архив и SHA-256 каждого исходного MP4.
- `review-notes.json` — визуальные комментарии и времена эпизодов.
- `*-detections.mp4` — все кадры с настоящими рамками и временем.
- `*-predictions.jsonl` — последовательность кадров с нормированными координатами,
  классами, score, цветом, исходным PTS, временем воспроизведения.
- `*-storyboard.jpg` — по 12 равномерных кадров; `*-poster.jpg` — середина ролика.

Источник: [p25543770-lang/yolo-stop, закреплённый commit](https://github.com/p25543770-lang/yolo-stop/tree/3cb277bfadf7d0034943117f9146d4b92bb773a9).
Архив и все восемь исходных MP4 проверены по сохранённым SHA-256.
Исходные тяжёлые медиа находятся в игнорируемом `.cache/vision/video-review`,
а не дублируются в Git. Хэш проверенного кандидата:

```text
fd6f1514770a364471f2d0cedfe431bcce41c5f3f5969c7eb8eb9aaab9a1f76c
```

Для повторения поместите восемь оригинальных MP4 из закреплённого архива
(имена и хэши — в `source.json`) в `.cache/vision/video-review`, установите
`requirements-vision-review.txt` в отдельное окружение и выполните:

```bash
# Headless OpenCV: после установки зависимостей, до запуска:
.venv/bin/python -m pip uninstall -y opencv-python
.venv/bin/python -m pip install --force-reinstall --no-deps opencv-python-headless==4.11.0.86

.venv/bin/python scripts/review_vision_video.py \
  --source .cache/vision/video-review \
  --manifest docs/vision-video-review/source.json \
  --output docs/vision-video-review

# HTTP с поддержкой Range для перемотки видео:
npx --yes http-server@14.1.1 docs/vision-video-review -a 0.0.0.0 -p 8766 -c-1
```
