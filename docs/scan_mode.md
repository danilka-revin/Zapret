# Режим «Скан»: сначала карта, потом по ней ездим

Отдельная страница **`/scan`** для съёмки карты: камеры робота, живая карта
лидара и управление, которое оператор включает и выключает вручную. Задача
режима одна — быстро и аккуратно объехать помещение и получить карту, по которой
потом можно строить маршрут на `/navigation` (цель → маршрут → «Поехать»).

Это **не** автономия и не Nav2: робот едет ровно туда, куда его ведёт человек.
Никаких автоматических «объехать всё самому» здесь нет — для этого есть
«Обследование» на `/map`, но оно строит карту без участия оператора и требует
подтверждения слепой зоны лидара.

## Как снять карту

1. Поставьте робота в точку старта, откуда вы будете возвращаться.
2. Откройте `/scan`. Сетка пустая — нажмите **Новая карта**, если на экране
   остался прошлый объезд.
3. **Включить управление**. Кнопки движения разблокируются только после этого.
4. Медленно объезжайте помещение. Тяга по умолчанию 8 %, потолок — 20 %
   (`RC_SCAN_MAX_PERCENT`). Чем медленнее, тем меньше шансов, что сопоставление
   сканов «съедет» и стены задвоятся.
5. Вернувшись к старту, нажмите **Сохранить карту** — на рабочем столе
   обновятся `rus_slam_map.pgm`, `.yaml` и `.png`.
6. Для поездки: `/navigation` → выбрать цель → **Построить маршрут** → **Поехать**.

После перезапуска бортового сервера карта на экране пустая: нажмите
**Загрузить карту** в режиме «Скан» — прочитается последний сохранённый файл.
Поза при загрузке обнуляется, поэтому робот должен стоять в той же точке, где
начинал съёмку, и получить свежий скан лидара прежде, чем ехать.

## Управление включено ≠ управление навсегда

Режим намеренно устроен так, чтобы «забыл выключить» не превращалось в «робот
уехал»:

| Что произошло | Что делает режим |
| --- | --- |
| Кнопка **Выключить** | Сначала STOP на шасси, потом снятие управления |
| `Esc` | То же самое |
| Кнопку движения отпустили | Немедленная нулевая тяга |
| Вкладку скрыли или ушли со страницы | Управление снимается, тяга гасится |
| Страница молчит дольше 5 с | Сервер сам снимает управление (deadman) и тормозит |
| Включение | Сначала STOP: включаемся только на стоящем роботе |
| E-STOP взведён | Управление не включается |
| Другая вкладка включила управление | Старый токен перестаёт действовать |

Пока управление выключено, кнопки движения заблокированы в разметке, а сервер
отвечает `409 scan_disabled` даже если команду отправить напрямую. Исключение
одно: **нулевая тяга (стоп) проходит всегда** — остановка не должна требовать
разрешения.

Прошивка колёс всё равно гасит движение через 650 мс без heartbeat: сервер
присылает тягу повторно каждые 250 мс, пока кнопка (или клавиша) удерживается.

## Предел тяги

`RC_SCAN_MAX_PERCENT` (по умолчанию **20 %** шкалы Servo) ограничивает только
этот режим. Предел проверяется на борту: команда больше него отклоняется с
`400 drive_limit`, а не подрезается молча.

Зачем так мало: съёмка карты — это про качество сопоставления сканов, а не про
скорость. На 20 % робот проходит метр за несколько секунд, зато лидар успевает
сопоставить каждый кадр.

## API

| Маршрут | Метод | Что делает |
| --- | --- | --- |
| `/api/scan_mode` | GET | Состояние: включено ли, токен, предел тяги, статистика карты |
| `/api/scan_mode/enable` | POST | STOP, затем включение; отказ, если шасси не подтвердило торможение |
| `/api/scan_mode/disable` | POST | STOP и снятие управления |
| `/api/scan_mode/heartbeat` | POST | Продлить окно (тело — `{"token": …}`) |
| `/api/scan_mode/drive` | POST | Тяга: `{"percent": N}`; ноль разрешён всегда |
| `/api/scan_mode/steer` | POST | Угол колеса: `{"module": "FL", "angle": 20}` |
| `/api/scan_mode/map/load` | POST | Прочитать карту из файла (PGM рядом с YAML) |

Тяга и руление дополнительно требуют заголовок `X-Scan-Token`, если управление
включено. С веб-пульта (8080) эти маршруты проксируются на борт и требуют
CSRF-токен сессии и заголовок `X-Robot-Control: scan`.

## Ограничения, о которых нужно помнить

- Лидар видит одну плоскость. Низкие, прозрачные, тонкие и нависающие
  препятствия, а также перепады пола он не увидит — их видит оператор, а не
  карта.
- Камеры на странице — только глаза оператора: они не пишутся в карту и не
  участвуют в сопоставлении. Четыре C930e показывают по одному кадру на
  запрос, без записи видео.
- Лента внизу рамы светит на пол: если в помещении темно, стены на камерах
  видны хуже. Снимайте карту при включённом свете.
- Физический E-STOP остаётся обязательным: режим его не заменяет и не
  дублирует.
