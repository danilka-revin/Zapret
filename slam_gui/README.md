# Пульт и экран робота

Веб-интерфейс проекта Zapret преобразован в пульт 4WIS/4WID и бортовой экран.
Основной экран (`main.html`) показывает телеметрию; экран робота (`robot.html`)
доступен на порту 8090. Инженерная панель и киоск используют одну серверную
службу данных. В киоске функции доступны без PIN, PIN запрашивается только для
открытия кейса; веб-пульт оператора сохраняет собственную авторизацию руля.

## Запуск и обновление

Обычный запуск — один ярлык **«Запустить робот»**, который создаёт
`./scripts/make_shortcut.sh`, либо команда:

```bash
./scripts/start_robot.sh
```

Она запускает пульт на 8080 и киоск на 8090, проверяет зависимости один раз и
не создаёт дубли при повторном запуске. Ctrl+C или `./scripts/stop.sh`
останавливает запущенный комплект. На экране пульта кнопка **«Обновить»**
совместно обновляет сервер и веб-интерфейсы; прошивки Arduino она не загружает.

В `.env` по умолчанию используется `RC_SLAM_SOURCE=master` и
`RC_SLAM_PORT=/dev/ttyACM0`. Без USB-мастера состояние отображается как
недоступное, без выдуманных данных. Демо-режима нет: без робота задайте
`RC_SLAM_SOURCE=none`, и все значения будут пустыми.

## Карта и камеры

В веб-пульте (`8080`) пункт **«Карта лидара»** на главном экране и в
инженерной консоли открывает `/map`. Это та же
карта, что на бортовом экране: запросы снимка, настроек, сохранения и сброса
сервер пульта передаёт бортовому процессу (`RC_KIOSK_PORT`, по умолчанию 8090).
В браузере используются только относительные адреса — никаких обращений к
`localhost` компьютера оператора. Без работающего бортового сервера появится
сообщение об отсутствии связи; отдельная карта не создаётся. Веб-страница и
её API требуют входа оператора.

На бортовом экране ссылка **«Карта»** в шапке открывает отдельную страницу
`/map` без PIN. Она работает даже при сбое загрузки `robot.js` или
инициализации телеметрии. Карту по-прежнему можно открыть внутри экрана через
**«Функции → Карта»**; загрузка данных начинается сразу после показа страницы.

Кнопка **«Камеры»** в шапке открывает камеры и журнал без
свайпа. Свайп-навигация тоже сохранена; для перехода между страницами делайте
жест по шапке или вне изображения. Страница камер всегда тёмная, даже если
для главного экрана выбрана светлая тема.

* Камеры: кнопки **+/−**, колесо мыши или два пальца — цифровой зум 1–8×;
  увеличенное изображение можно перетаскивать. **«Сброс»** возвращает 1×,
  **«Развернуть»** скрывает вторую камеру и журнал, **«Свернуть»** возвращает их.
* Карта: те же жесты и кнопки **+/−**, **«Вписать карту»** сбрасывает масштаб
  и сдвиг. На канве работают клавиши **+**, **−**, **0**.
* Камеры берутся с бортового сервера по фиксированным ID: 0 — передняя,
  1 — задняя. Отключённая передняя не мешает задней. При обрыве кадры
  запрашиваются повторно, при закрытии страницы опрос прекращается.
  Браузер не запрашивает доступ к веб-камере планшета и не конкурирует с
  сервером за USB-порт. Порты настраиваются кнопкой **⚙** в шапке камер.

## Четыре платы Arduino Mega/Mega Mini

`firmware/motor_master/motor_master.ino` — мастер (рулевой модуль FL), USB Serial
115200 бод и I²C-мастер. `firmware/motor_node/motor_node.ino` — общая прошивка
трёх слейвов: FR (адрес 2), RL (3), RR (4). Мастер посылает адресные команды
руления и синхронные команды тяги. Инструкция сборки, подключения и проверки:
[`firmware/README.md`](../firmware/README.md).

### Руление

Перед командами угла физически выставьте колесо прямо и задайте ему программный
ноль кнопкой «Задать 0°». Это действие не двигает мотор; после перезапуска платы
ноль задают снова. Оптопара/вход D18 сейчас не используется. Поворот ограничен
±32° и разрешён только на остановленном модуле.

### Тяга BLDC — только безопасный стендовый режим

Тяга ограничена ±20%, разрешается только при свежей телеметрии всех четырёх
плат, ручном нуле и выравнивании рулевых модулей в пределах 2,5°. Направление
передаётся, пока оператор удерживает кнопку; отпускание отправляет тормоз. UI
повторяет heartbeat каждые 200 мс; мастер и каждый слейв выключают PWM и включают
тормоз после 650 мс без команды.

Это прототип, не сертифицированная система безопасности. **Не испытывайте тягу
с колёсами на земле.** До краткого теста с вывешенными колёсами проверьте
полярность сигналов и подключите независимый физический аварийный выключатель
в силовую цепь. PWM на D3 — цифровой PWM, не аналоговый 0–5 В; если ваш
контроллер ожидает аналоговый вход, необходимы подходящие фильтр/буфер или ЦАП.

## Разработка

```bash
python3 -m compileall -q robot_control slam_gui tests
node --check slam_gui/robot.js
node --check slam_gui/steering.js
```

Тесты Python находятся в `tests/`; запуск — `python3 -m pytest -q` после
установки `requirements-dev.txt`.
