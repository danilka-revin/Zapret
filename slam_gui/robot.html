    Тяга и руление

    1) выберите режим · 2) колёса встанут на угол · 3) кнопки движения — в самом низу экрана

    доступ без PIN
    USB-порты колёс · ручное назначение

    Для каждого колеса выберите имя его порта: /dev/ttyUSB0, /dev/ttyACM0 и т. п. Автоопределение отключено. «Не подключено» оставляет колесо отключённым. Имена в прошивке не используются. Номера портов могут измениться после переподключения USB.

    Остановите робот перед изменением. После сохранения перезапустите программу для применения.

    Режим движенияПресет выставляет все четыре колеса в пределах ±100°. Кнопки движения — в самом низу экрана: удерживайте их.
    Проверка связи…
    0°

    Плюс — вправо, минус — влево, как в телеметрии; ход ±100°. Пресет не включает тягу.
    ПЕРЕД вид сверху · цель
    0° Прямо · движение вперёд/назад Схема показывает целевой угол. Фактический угол каждого колеса — в точной настройке ниже, кнопки движения — в самом низу.

    Проверка связи с модулями…

    Ноль руля — по оптодатчику D18 Колесо ищет флажок в пределах ±135° (ход руля 270°): сначала вправо, затем влево. Подходит к каждой кромке по три раза и встаёт в середину флажка по среднему. После включения Arduino выставьте колёса прямо руками (±30°). Колёса не должны упираться, рядом — никого.

      Ноль задаёт «Калибровка» по оптодатчику D18; «0° вручную» — запасной вариант, если датчик снят. Ноль сбрасывается при перезапуске Arduino. Пресеты и общий ползунок выставляют цель всем четырём колёсам в пределах ±100°: 0° — прямо, 45° — диагональ (краб), 90° — чистый боковой ход. Тяга включается только удержанием кнопок «Движение» в самом низу экрана и лишь при совпадении углов в пределах 2,5°. Разворот на месте эта прошивка не выполняет: у неё одна тяга на все колёса.

      Выберите V4L2-устройство для каждой камеры. Путь /dev/v4l/by-id/… стабилен после перезагрузки; /dev/video0 может меняться. Порты сохраняются в .env (RC_CAMERA_FRONT / RC_CAMERA_REAR) и применяются сразу без перезапуска. Настройка доступна без PIN.
